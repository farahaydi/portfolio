# Farah Elaydi — Portfolio

A single-page personal portfolio, designed in Figma and built with pure HTML & CSS.

**Live Demo:** https://farahaydi.github.io/portfolio/
**Figma Design:** https://www.figma.com/design/bq6MYUEOgQAygKIsLGjMUM/Farah-Portfolio--Copy-

## Sections
- Navbar — name + links (Projects, Skills, About, Contact)
- Hero — intro + resume button
- Skills — Frontend / Backend / Tools cards
- Projects — Petly, Ricepify, JobScouts
- About — bio + photo
- Contact — form (email, message)
- Footer — social icons + copyright

## Built With
- HTML5 & CSS3 only — **no JavaScript**, no CSS frameworks except Bootstrap for the navbar
- Figma for UI/UX design

## Run Locally
```bash
git clone [your-repo-url]
cd portfolio
```
Open `index.html` in your browser, or use the Live Server extension in VS Code.

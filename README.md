## 📖 About the Project

This is a personal portfolio website that showcases my skills, projects, and contact information. The project started with a UI/UX design process in Figma (wireframes and mockups) before moving into development using HTML and CSS.

---


## 🗂️ Sections / Pages

Single-page portfolio, based on Figma design:

- [ ] Navbar — Name/logo (Farah Elaydi) + links (About, Work, Contact) + "Resume" link
- [ ] Hero — Heading "A Full Stack Developer" + intro text + photo
- [ ] Bio / About section — "Welcome to my digital playground" + photo + bio text
- [ ] My Latest Work — Project grid (6 cards: Petly, Ricepify, Jopscouts, American Girl, Whole Lotta Love, Under Pressure)
- [ ] Technologies I Master — 3 cards (Frontend, Backend, Tools & Others) with tag pills
- [ ] Contact — "Let's work together" text + form (Name, Email, Message, Submit)
- [ ] Footer — Social icons + copyright

## 🎬 Animations

Animations to add using CSS (`transition`, `@keyframes`, `transform`):

- [ ] Navbar links — underline/color transition on hover
- [ ] "Hire Me" button — hover scale or color transition
- [ ] Hero section — fade-in / slide-up on page load
- [ ] Project cards — hover scale/lift effect (`transform: scale()` + shadow)
- [ ] Tech stack pills — subtle hover effect (color/border transition)
- [ ] Submit button — hover state transition

**Note:** This project uses **only HTML and CSS — no JavaScript and no Bootstrap** (or any other CSS framework). All animations are done with pure CSS (`transition`, `transform`, `@keyframes`). Scroll-triggered animations are skipped since they require JS.
